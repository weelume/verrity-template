# 验收说明

当前结果以 `../reports/verification.json` 的源码摘要为准。格式检查仅证明协议结构与交付文件关系，不代替应用、视觉或交互验证。

自动检查：

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm lint
pnpm test
pnpm build
node .tpl/tools/check.mjs .
```

行为测试覆盖价格计算、双语路径的参数与锚点保留，以及双语数据解码和缺项拒绝。生产服务启动后核对全部中英文路由、未知路径 404、运行素材下载及控制台日志。

页面检查视口为 PC 1440×1000、平板 834×1180、手机 390×844，补测 320px。分别检查首页、价格、集成、关于、招聘、博客、文章、联系、更新日志、登录、注册、职位和政策。记录视口、扣除滚动条后的内容宽度和截图实际像素，不放大截图。

交互检查包含：价格联动与数字切换、集成/文章/职位分类、团队肖像、工作流程、功能轮播拖拽与键盘、评价切换、FAQ、菜单 Escape 与焦点返回、语言路径、便笺表单错误和本地校验成功、文件类型与大小拒绝。

动效须观察初始、运行和结束状态。循环检查离屏与悬停的暂停条件，门体和插头检查位置随时间变化；不能用单张截图替代。减少动态效果的代码分支存在，但未实际切换系统设置时必须记录为未实机验证。

原站没有观察到视频标签或视频运行素材，动态工作台和线框场景由 DOM/SVG 构成。线框投影、弹性与节奏按可见状态重建，未证明每条轨迹与原站逐帧完全一致；中文字体与字号按本项目排版规则有意调整。
