# 素材来源

参考站： https://verrity.framer.website/ 。照片、Logo、签名与博客封面由页面中实际观察到的 `framerusercontent.com` 素材下载并本地保存，逐项 URL、字节数和 SHA256 见 `assets.json`。价值观线框图来自已渲染 SVG，插头几何以路径数据保存，门体按可见几何重建；均属于参考设计的权利范围。

运行目录为 `public/templates/verrity/images/` 和 `public/templates/verrity/fonts/`，页面不使用图片或字体热链。没有将视频替换为静态图片；已检查页面未观察到视频运行素材。

- MiSans Normal Regular/Bold：真实 400/700 字重及 Unicode 分片，来源和许可入口 https://hyperos.mi.com/font/ ，适用官方知识产权许可协议。
- Poppins Latin：400/600/700，来源 https://github.com/itfoundry/Poppins ，完整 OFL 许可随字体保留。
- 应用内日落 Mark 和图标入口为本项目 SVG；无独立图标依赖。
- 市场截图在 `.tpl/assets/`，由实际本地页面拍摄，尺寸按解码结果填写。
